# P1.2 — Acceptance Plan

Use the deployed build at:

```text
https://unbound-journal.pages.dev/?qa=1
```

## Automatic gate

`Run self-check` must contain no FAIL result for:

- viewport / DPR
- unified PageDocument round-trip including InkElement data
- P0 → P1 migration regression
- Ink vector partial-erase geometry
- Paper runtime hydration
- persistence state
- IndexedDB round-trip

## Handwriting / Drawing

1. Enter Draw from the bottom tool dock.
2. Test Handwriting and Drawing separately.
3. Change Pen/Marker, color, width, and opacity.
4. Draw at least five strokes.
5. Confirm every completed gesture adds exactly one Undo entry.
6. Confirm pointermove does not produce multiple History entries.
7. Zoom/pan, then draw again; ink must remain under the finger.
8. Undo / Redo several strokes.

## Mobile two-finger cancellation

On iPhone Safari and standalone Android Chrome:

1. begin a one-finger ink stroke
2. without lifting it, add a second finger
3. the uncommitted Ink preview must disappear
4. no new InkElement / History entry may be created
5. pinch/pan must proceed normally
6. one-finger drawing must remain suppressed until all touches lift

## Ink Eraser

1. Draw crossing Pen and Marker strokes.
2. Enter Ink Erase.
3. Erase through the middle of multiple strokes in one continuous gesture.
4. Confirm partial pieces disappear during the gesture preview.
5. Confirm Paper and placeholder content remain unchanged.
6. Pointerup must add one History entry.
7. Undo must restore all erased vector portions.
8. Redo must reapply the same erase.
9. A tap with the eraser must also erase a local ink region.

## Selection compatibility

1. Enter Select through QA controls.
2. Select a committed ink stroke.
3. Drag it.
4. Confirm vector geometry remains intact.
5. Undo / Redo the drag.

## Persistence

After creating and partially erasing ink:

1. wait for `Saved locally`
2. reload
3. require the same paper, placeholders, ink colors, widths, opacity, retained paths, transforms, and ordering
4. History should restart from an empty session baseline after reload

## Stress

Use:

- `+5 paper layers`
- `+20 ink strokes`

Then draw, erase, zoom, and pan on mobile. No obvious freeze, large flash, coordinate drift, or sustained interaction lag is acceptable.

## Device gate

- Desktop Chrome
- iPhone Safari
- standalone Android Chrome

P1.2 closes only after CI and real-device Ink tests pass.
