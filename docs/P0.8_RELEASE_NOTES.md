# P0.8 Release Notes

## Delivered

- Native IndexedDB document storage adapter
- Generic debounced autosave controller with serialized writes
- `PaperPageDocumentV1` persisted schema
- Strict persisted-document decode / validation boundary
- 450 ms autosave after committed History transitions
- Autosave on Paint / Erase / Fill / Replace / Clear / Undo / Redo
- No persistence writes during pointer/touch movement
- Startup restore before paper editing is enabled
- Restored `paperVersionId` runtime-asset rehydration
- Restore creates a fresh History baseline instead of persisting session Undo/Redo stacks
- Best-effort pending-save flush on `pagehide` / hidden visibility state
- Local persistence status surfaced in the editor HUD
- English / Japanese / Korean / Traditional Chinese persistence status strings
- Cloudflare remains explicitly deferred

## Browser runtime QA still required

Native IndexedDB behavior must be verified in a normal browser environment:

1. Create a multi-layer paper page.
2. Wait for `Saved locally`.
3. Reload and confirm all layers / masks restore.
4. Confirm runtime textures for multiple paper versions rehydrate.
5. Edit, Undo, reload, and confirm the post-Undo state is what persists.
6. Test iPhone Safari private/normal browsing behavior.
7. Test Android Chrome storage behavior.
8. Test IndexedDB unavailable/error fallback.
