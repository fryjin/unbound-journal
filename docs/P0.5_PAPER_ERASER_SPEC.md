# P0.5 Paper Eraser Spec

## Goal

Add physical-paper-style erasing to the existing Paper Engine without allowing one continuous erase gesture to punch through multiple PaperLayers.

## Frozen interaction rule

A Paper Eraser gesture resolves exactly one target PaperLayer at gesture start.

```text
pointer/touch start
↓
query page point
↓
find top visible PaperLayer
↓
lock targetLayerId
↓
erase only that layer until gesture end/cancel
```

If the user erases completely through that layer during the gesture, lower paper becomes visible, but the current gesture does **not** switch targets.

To erase the newly revealed lower layer:

```text
lift finger
↓
start a new erase gesture
↓
run top-visible hit test again
```

## Hit testing

Hit testing is renderer-independent and lives in `paper-engine`.

For one logical point, mask strokes are replayed in document order. A hard round paint stroke makes the point visible; a later hard round erase stroke makes it invisible. The last stroke that geometrically covers the point determines current visibility.

The algorithm uses point-to-polyline distance against `stroke.size / 2`, matching the P0 hard round brush semantics.

Top-layer detection iterates PaperLayers from top to bottom and selects the first layer whose mask is visible at the gesture start point.

## Active erase architecture

High-frequency erase input must not update React document state on every move.

```text
single-finger move
↓
PaperStackHandle
↓
locked PaperMaskedTextureHandle
↓
mutate target layer outputCanvas with destination-out
↓
Konva layer batchDraw
```

Each PaperLayer already owns its own raster cache, therefore `destination-out` is applied only to the target layer image and cannot damage lower layers.

On gesture end:

```text
active points
↓
createEraseStroke(...)
↓
append to target PaperLayer.maskStrokes[]
↓
React document state updates once
↓
committed layer rerenders from vector mask history
```

## Cancellation

If a second finger joins during erasing:

1. PageViewport cancels the single-finger input.
2. PaperStack tells the locked PaperMaskedTexture to cancel.
3. The target layer redraws from committed vector mask strokes.
4. No erase stroke enters document state.
5. Painting/erasing stays suppressed until all fingers lift.

## Tool separation

Paper tool now has two explicit modes:

- Lay Paper
- Erase Paper

The Paper Eraser is not shared with future Ink Eraser behavior.

## P0.5 out of scope

- Undo / Redo
- Fill Page
- Replace Paper while preserving mask
- layer panel UI
- erasing raster image/text/ink content
- pressure/opacity eraser
- torn/wavy eraser styles
- automatic removal of fully empty PaperLayers

## Acceptance

1. Create lower Paper A and overlapping upper Paper B.
2. Start erasing on the overlap: Paper B is targeted.
3. Keep the same finger down and erase until A is exposed: A remains untouched.
4. Lift the finger.
5. Start erasing again at the same point: A can now be targeted.
6. Start erasing at a point where only A is visible: A is targeted immediately.
7. Start on blank base paper: nothing is erased.
8. Add a second finger during an unfinished erase: the preview is cancelled and committed state is restored.
9. Zoom/pan, then erase: logical coordinates remain correct.
10. A single tap creates a valid round erase dot.
