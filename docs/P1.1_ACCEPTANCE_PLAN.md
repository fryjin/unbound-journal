# P1.1 — Acceptance Plan

Use the deployed Cloudflare Pages build with:

```text
https://unbound-journal.pages.dev/?qa=1
```

## Automatic gate

Run `Run self-check` and require no FAIL result for:

- viewport / DPR
- unified PageDocument V2 round-trip
- P0 → P1 migration
- runtime paper hydration
- persistence state
- IndexedDB round-trip

## Content foundation flow

1. Add two `+ placeholder` elements so they overlap.
2. Enter Select mode.
3. Tap/click the overlap and verify the top element selects.
4. Drag it; verify responsive preview and one new Undo entry at gesture completion.
5. Undo and Redo the drag.
6. Rotate +15° and Scale +10%; verify each is individually undoable.
7. Send back and verify the overlapping hit target changes.
8. Bring front and verify it changes back.
9. Start dragging and introduce a second finger on mobile; verify the uncommitted drag is cancelled while the viewport gesture proceeds.
10. Wait for local save, reload, and verify Paper + Content are restored.
11. Remove a selected placeholder; Undo must restore it at the same z-order position.

## Paper regression flow

With content visible above paper:

- Lay paper under content
- Erase paper under content
- Fill page
- Replace top paper
- Undo / Redo
- confirm content remains visually above active and committed paper

## Device gate

- Desktop Chrome
- iPhone Safari
- standalone Android Chrome preferred; Android Chromium WebView may be additional coverage

P1.1 is an architecture milestone; visual polish is not an acceptance requirement.
