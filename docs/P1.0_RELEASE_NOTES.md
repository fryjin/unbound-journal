# P1.0 — Release Notes

## Planning result

P1.0 freezes the Content Stack & Product Shell execution plan.

No user-facing feature code is introduced by this planning patch.

## Main decisions

- P0 paper-only persisted state will evolve into a unified PageDocument before Ink/Image/Text implementation.
- Content z-order uses `elements[]` array order.
- Selection and common transforms are shared infrastructure.
- P1 remains renderer-independent and local-first.
- Image binaries will use IndexedDB asset records referenced by `assetId`.
- Text editing will use DOM composition/IME with Canvas/Konva display.
- Ink and Drawing share one vector engine but remain separate UI modes.
- Multi-page journals store page records separately.
- Video, cloud sync, accounts, marketplace, and creator center stay out of P1.
- Cloudflare Pages remains the static QA deployment; Workers/D1/R2 remain deferred.
- `emilkowalski/skills` becomes a design-engineering review reference from P1.6 onward.

## P0 closeout correction

The existing Android P0 report is from Android Chromium WebView rather than standalone Chrome. This is recorded as a non-blocking browser-coverage closeout item.
