# P0.2 Release Notes

- Real Konva Stage viewport

- Fit transform and coordinate conversion helpers
- Pinch zoom: Fit → 4×
- Simultaneous two-finger pan + zoom
- Viewport edge clamping
- Resize/orientation handling
- Page content clipping boundary for future Paper Renderer
- Public coordinate/fit handle for future tools
- Desktop wheel zoom for QA
- Localized P0.2 viewport HUD for en / ja-JP / ko-KR / zh-Hant
- P0.2 architecture/status documentation

## Validation completed in generation environment

- `npm run papers:validate` → 40 papers valid
- `editor-core` strict TypeScript check → pass
- Viewport math round-trip / focal zoom / clamp edge-case checks → pass
- Renderer TSX structural check with local dependency stubs → pass

## Validation blocked by environment

Full workspace dependency installation/build is not available in the generation environment because its internal npm registry returns 404 for public package `prettier`.

Before deployment, run in a normal npm environment:

```bash
npm install
npm run typecheck
npm run build
npm run papers:validate
```

## Manual mobile QA required

P0.2 should be manually verified on:

- iPhone Safari
- Android Chrome
- Desktop Chrome

Check:

1. Full page fits at launch.
2. Two fingers pinch between Fit and 4×.
3. Two-finger movement pans while zooming.
4. A single finger does not move the viewport.
5. The page cannot be thrown completely off-screen.
6. Fit control returns to centered full page.
7. Orientation/viewport resize preserves relative zoom.
8. Canvas remains sharp on Retina/high-DPR screens.
