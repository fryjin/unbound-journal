# P1.2 — Release Notes

## Added

- real vector `InkElement` content type
- shared `@unbound-journal/ink-engine` workspace package
- Handwriting / Drawing / Ink Erase editor modes
- Pen / Marker, color, width, opacity controls
- renderer-only active Ink stroke preview
- renderer-only incremental partial eraser preview
- vector partial erase that preserves disjoint retained paths
- one Ink gesture / eraser gesture per History operation
- Select-mode hit testing for committed Ink
- IndexedDB persistence and PageDocument V2 round-trip for Ink
- P1.2 QA report with Ink counts and vector erase self-check
- `+20 ink strokes` stress fixture
- Tier-1/Tier-2 localized Ink UI

## Preserved

- Paper Engine interaction semantics
- P0 → P1 migration
- unified `CommandHistory<PageDocument>`
- Content z-order
- two-finger viewport ownership
- local-first autosave

## Deferred

- stylus pressure optimization
- advanced brushes/calligraphy
- lasso/multi-select
- ImageElement
- TextElement
- Cloudflare Workers/D1/R2
