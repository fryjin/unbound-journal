## P0.9 acceptance gates

P0 closes only after all of the following are true:

- GitHub Actions `P0 validation` is green.
- Desktop Chrome core flow passes.
- iPhone Safari core flow passes.
- Android Chrome core flow passes.
- IndexedDB save/reload recovery passes on normal mobile browsing.
- IndexedDB restricted/unavailable behavior degrades gracefully.
- Five-layer stress flow remains usable.
- No blocker remains in Paper Brush / Eraser / Fill / Replace / History / Persistence.
- Final novice-user task completes.

## Deployment dependency

A static HTTPS preview is now required to finish the physical-device portion of P0.9. Cloudflare Pages is sufficient; no backend Cloudflare services are required for P0 acceptance.

Until that preview and the device results exist, the correct milestone state is:

```text
P0.9 implementation / QA harness: ready
P0 final acceptance: pending device QA
```
