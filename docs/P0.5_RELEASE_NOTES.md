## Architecture notes

The eraser deliberately does not perform `destination-out` on a shared Konva Layer. It mutates only the locked PaperMaskedTexture's own output canvas. This preserves PaperLayer isolation and guarantees that lower layers cannot be punched through by renderer compositing.

Logical mask history remains vector data. Raster canvases remain renderer caches only.
