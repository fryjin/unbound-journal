# P0.6 Release Notes

## Delivered

- `createFillPageStroke()` renderer-independent full-page mask helper
- Fill Page action using the existing vector `paint` mask contract
- Same-paper Fill reuses the current top PaperLayer
- Different-paper Fill creates a new top PaperLayer only when Fill is invoked
- `replacePaperLayerFromAsset()` material replacement helper
- Replace preserves layer identity, creation time, layer order and exact mask history
- Replacement texture resets to the new Paper asset defaults
- P0.6 UI replaces only the current top PaperLayer; no premature layer manager
- Fill / Replace cancel active uncommitted brush or erase previews before mutation
- Fill / Replace disabled during Erase mode
- English / Japanese / Korean / Traditional Chinese action labels and accessibility text
- P0.6 specification and project status update

## Validation completed in generation environment

- Starter Paper Pack validator: 40 papers valid (24 Pattern / 16 Full-sheet)
- `editor-core + paper-engine` strict TypeScript check: pass
- Fill geometry assertions: page center, edges and all four corners visible
- Replace assertions: stable ID / createdAt / mask history; new paperVersionId / texture defaults
- P0.6 locale key validation: en / ja-JP / ko-KR / zh-Hant pass
- Modified TS / TSX syntax and type-structure checks pass

## Environment limitation

Full workspace dependency installation/build remains unavailable in the generation environment because its configured npm registry cannot resolve all public dependencies.

Before deployment, run in a normal npm environment:

```bash
npm install
npm run typecheck
npm run build
npm run papers:validate
```

## Manual QA required

1. Fill on an empty mobile page.
2. Brush/erase some regions, then Fill with the same paper and confirm the entire page becomes paper again.
3. Select another paper and Fill; confirm it becomes a new top full-page layer.
4. Erase the new full-page layer and confirm lower paper is revealed.
5. Create an irregular top mask, select another paper, press Replace top, and confirm the irregular shape is unchanged.
6. Confirm Replace top changes no layer count.
7. Confirm Fill / Replace are disabled in Erase mode.
8. Check English, Japanese, Korean and Traditional Chinese on narrow mobile widths.
