# P0.9 Release Notes

## Delivered

- Query-gated browser/device QA harness at `?qa=1`
- Real browser IndexedDB write/read/delete self-check using an isolated QA database
- Paper document encode/decode runtime self-check
- Runtime asset hydration count vs. persisted PaperLayer count
- Viewport / DPR / touch-capability diagnostics
- History / persistence / layer / stroke diagnostics
- Copyable device QA report
- Manual high-signal mobile checklist inside the QA harness
- One-click five-full-layer stress scenario using real paper assets and normal History commands
- Stable `data-qa` markers on core P0 controls
- Dependency-free P0 contract validator
- GitHub Actions workflow for normal-environment install, typecheck, build, paper-pack validation, and P0 contract validation
- Executed Mobile QA plan and explicit P0 acceptance report

## Normal product boundary

The QA harness is rendered only when the URL contains:

```text
?qa=1
```

Normal editor URLs do not render the QA panel.

## Acceptance boundary

P0.9 is not considered fully accepted by static checks alone. Final acceptance still requires:

- green GitHub Actions full build
- Desktop Chrome
- iPhone Safari
- Android Chrome
- real IndexedDB reload/recovery checks
- five-layer stress checks
- final novice-user test

## Cloudflare

P0.9 is the first milestone where a static Cloudflare Pages preview is needed to complete physical-device QA. No Workers, D1, R2, accounts, or cloud sync are introduced.
